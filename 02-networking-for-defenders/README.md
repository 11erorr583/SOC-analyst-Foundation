# Task 02: Networking Basics for Defenders

**Date:** 13 November 2026  
**Focus:** Networking concepts relevant to defensive security  
**Status:** Completed

## Objectives

- Map the seven OSI layers and common protocols.
- Document common network ports and their services.
- Explain the DNS resolution process.
- Compare examples of normal and suspicious network traffic.

## Topics Covered

- OSI model and protocol mapping
- Common services and ports, including SSH (22), DNS (53), HTTP (80), HTTPS (443), SMB (445), and RDP (3389)
- DNS resolution, including local lookup/cache, recursive resolver, root, TLD, and authoritative DNS servers
- Traffic indicators such as source IP, connection frequency, authentication results, timing, and flow patterns

## Practical Work and Evidence

- TryHackMe: What Is Networking?
- TryHackMe: Introductory Networking
- Windows `tracert` command
- WHOIS lookup for Microsoft.com
- Supporting screenshots from the exercises

## Learning Outcome

Developed a foundation in network architecture, common services, DNS resolution, and traffic characteristics that can help an analyst recognize potentially suspicious activity.
